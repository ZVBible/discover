# ZVBible Discover

This is the public place to talk with the ZVBible team. Use it to report problems, request features, ask questions, or send other feedback about [ZVBible](https://zvbible.com).

## How to reach us

[Open a new issue](https://github.com/ZVBible/discover/issues/new/choose) and pick the type that fits:

- **Problem report**: something isn't working, looks wrong, or shows the wrong text.
- **Feature request**: an idea for something new or a way to make ZVBible better.
- **Feedback or question**: anything else you'd like to tell or ask us.

Before you open a new issue, please [search existing issues](https://github.com/ZVBible/discover/issues) in case someone has already raised it. If they have, add a 👍 or a comment there.

## Tips for a helpful report

- Say what you were doing, what you expected, and what happened instead.
- Include the book, chapter, and verse if it's about a passage.
- Mention your device, browser or app, and language.
- Screenshots help a lot.

Please don't post personal information, such as passwords or private notes, in an issue. Everything here is public.

## Code of conduct

Be kind and respectful. Issues that are abusive or off-topic may be closed.
